# راهنمای اجرای محلی و اعتبارسنجی

## پیش‌نیازها

- Java 17 یا جدیدتر
- Maven
- برای اجرای اولیه هیچ Docker، اینترنت یا کلید مدل لازم نیست.

## پیکربندی

حالت پیش‌فرض `AGENT_MODE=MOCK` است. توکن مدیر را برای محیط محلی تنظیم کنید؛ هیچ مقدار واقعی را در مخزن قرار ندهید:

```text
ADMIN_API_TOKEN=<local-secret>
AGENT_MODE=MOCK
```

برای حالت REAL، `WRITER_BASE_URL`، `WRITER_MODEL`، `WRITER_API_KEY`، `WRITER_TIMEOUT_SECONDS` و متغیرهای متناظر `REVIEWER_*` را جداگانه تنظیم کنید. timeout پیش‌فرض هر ایجنت ۳۰ ثانیه است.

## اجرا

از ریشه پروژه پس از ایجاد برنامه Maven:

```powershell
mvn spring-boot:run
```

مستند OpenAPI/Swagger باید عملیات تعریف‌شده در [قرارداد API](contracts/openapi.yaml) را نمایش دهد. پایگاه H2 پروفایل پیش‌فرض محلی است.

## سناریوهای بررسی دستی

1. با `POST /api/admin/articles/generate` و موضوع غیرخالی، پیش‌نویس DRAFT نسخه ۱ بگیرید؛ هدر `Authorization: Bearer <token>` لازم است و پاسخ MOCK باید `mock: true` داشته باشد.
2. موضوع خالی را بفرستید و بررسی کنید `400` برگردد و مقاله‌ای ساخته نشود.
3. مقاله را ویرایش کنید؛ نسخه جاری افزایش یابد و snapshot نسخه قبل در تاریخچه بماند.
4. بازبینی را صریحاً درخواست کنید؛ گزارش به شماره نسخه ورودی وصل شود. در MOCK، متن دارای `[NEEDS_FIX]` باید NEEDS_CHANGES بگیرد.
5. انتشار نسخه بدون گزارش APPROVED برای همان نسخه باید `409` بدهد. پس از تأیید نسخه جاری، انتشار دستی آن را در API عمومی قابل مشاهده کند.
6. بدون توکن معتبر مسیر مدیریتی باید `401` بدهد. مقاله منتشرنشده در مسیر عمومی باید `404` بدهد.
7. خطای adapter واقعی یا پاسخ نامعتبر باید محتوای قبلی را حفظ کند و مقاله را تأیید یا منتشر نکند.

## آزمون خودکار

پس از پیاده‌سازی، آزمون‌های پروژه با فرمان زیر اجرا می‌شوند؛ آزمون‌ها باید با MOCK و بدون اتصال بیرونی بگذرند:

```powershell
mvn test
```

موجودیت‌ها و قیدهای داده در [data-model.md](data-model.md) آمده‌اند.
