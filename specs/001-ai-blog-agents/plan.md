# برنامه پیاده‌سازی: وبلاگ با ایجنت‌های نویسنده و بازبین

**شاخه**: `001-ai-blog-agents` | **تاریخ**: 2026-10-20 | **مشخصات**: [spec.md](spec.md)

## خلاصه

یک سرویس یکپارچه REST با Java 17+ و Spring Boot 3.x، برای مدیریت مقاله‌های نسخه‌دار، اجرای صریح دو ایجنت مستقل و انتشار دستی نسخه‌ای که همان نسخه‌اش تأیید شده است. حالت MOCK پیش‌فرض، اجرای محلی را بدون کلید یا سرویس بیرونی ممکن می‌کند. طراحی شامل لایه‌های API، کاربرد، دامنه و ماندگاری است؛ هماهنگ‌کننده کاربردی هر ایجنت را از طریق قرارداد جداگانه فرا می‌خواند.

## زمینه فنی

**زبان/نسخه**: Java 17+

**وابستگی‌های اصلی**: Spring Boot 3.x، Maven، Spring Web، Spring Data JPA، Spring Security، springdoc-openapi؛ ArchUnit در محدوده آزمون برای اثبات مرز معماری. اتصال مدل از طریق API سازگار با OpenAI.

**ذخیره‌سازی**: H2 برای اجرای توسعه محلی؛ پروفایل اختیاری PostgreSQL. مقاله، snapshot نسخه‌ها، گزارش‌های بازبینی و اجرای ایجنت‌ها پایدار ذخیره می‌شوند.

**آزمون**: JUnit 5، Spring Boot Test و MockMvc؛ آزمون‌ها با پیاده‌سازی MOCK اجرا می‌شوند و به اینترنت یا کلید واقعی نیاز ندارند.

**بستر هدف**: سرویس محلی Java 17+؛ اجرای اولیه بدون Docker و حساب بیرونی.

**نوع پروژه**: سرویس وب REST، تک‌برنامه‌ای و یکپارچه.

**اهداف کارایی**: هدف ظرفیت یا تأخیر کلی در PRD مشخص نشده است. مهلت پیش‌فرض هر فراخوانی ایجنت ۳۰ ثانیه و قابل تنظیم است.

**محدودیت‌ها**: فقط عملیات REST؛ بدون فرانت‌اند. احراز هویت مدیر با Bearer token محیطی. رازها در مخزن، پاسخ‌ها و گزارش‌ها ثبت نشوند. ایجنت‌ها مستقل‌اند، حافظه یا فراخوانی مستقیم مشترک ندارند و ReviewAgent به مخزن مقاله دسترسی ندارد. تنها مدیر می‌تواند پس از تأیید همان نسخه انتشار دهد. خطا نباید داده یا وضعیت معتبر را خراب کند.

**مقیاس/دامنه**: نسخه نخست با یک مدیر، خوانندگان ناشناس و یک سرویس برنامه؛ بدون چندنویسندگی، ریزخدمت، صف پیام یا انتشار خودکار.
